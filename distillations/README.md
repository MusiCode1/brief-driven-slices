# distillations/ — שכבת הזיקוק

תיקייה זו מחזיקה את תוצרי הזיקוק: ניתוח כמותי ואיכותני של הדוחות שנצברו ב-`reports/`.

---

## שתי שכבות

| קובץ | מי כותב | מה |
|------|---------|-----|
| `<date>-data.json` | `scripts/distill.py` (כמותי) | ספירות, hitrate, דלתא, traceability — מספרים בלבד, אפס פרשנות |
| `<date>-report.md` | מרדכי-אוטומטי (opencode) | פרשנות הנתונים הכמותיים: מגמות, עדכוני-קטלוג, טקסונומיה |

---

## מבנה תיקייה

```
distillations/
├── README.md              ← זה הקובץ
├── TEMPLATE-report.md     ← תבנית לדוח הזיקוק
├── 2026-06-15-data.json   ← נתונים כמותיים (סקריפט)
├── 2026-06-15-report.md   ← דוח זיקוק (מרדכי)
└── ...
```

---

## הטריגר

הזיקוק רץ אוטומטית (systemd user timer, יומי):

1. `distill.py --check-only` בודק אם יש ≥N דוחות חדשים מאז ה-snapshot האחרון.
2. אם פחות מהסף — יציאה בשקט (זול).
3. אם מעל הסף — `distill.py` מחשב ומייצר `<date>-data.json`, ואז מרדכי-אוטומטי קורא אותו
   וכותב `<date>-report.md` לפי `TEMPLATE-report.md`.
4. **התוצר ממתין ב-branch ייעודי** (`bds-distill-<date>`) — **לא ממוזג ל-main** עד לאישור
   אנושי בבוקר.

הסף הנוכחי: `BDS_DISTILL_THRESHOLD` (ברירת מחדל: 10).

---

## החלוקה כמותי/איכותני

**`distill.py`** (הסקריפט) — **כמותי בלבד**:
- סופר findings לפי severity × category
- מחשב hitrate ו-avg_findings
- מייצר traceability (category → reports)
- מסמן קטגוריות לא-קנוניות (מועמדות לזיקוק-טקסונומיה)
- **לא מפרש, לא מנסח כללים** — זו עבודת מרדכי

**מרדכי** (המודל) — **איכותני**:
- קורא את ה-data.json ומפרש את המגמות
- מחליט אילו כללים להוסיף/להסיר מ-`plan-pitfalls.md`/`patterns.md`
- מתעד שינוי-טקסונומיה אם זוהתה קטגוריה חדשה משמעותית
