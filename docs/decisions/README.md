# Decisions — ‏יומן-החלטות של מרדכי

‏תיקייה זו מכילה יומני-החלטות של מרדכי (planner), ‏פר-פרויקט.

## ‏מבנה

```
docs/decisions/
└── <project>.md     # e.g. voice-acp.md, bds.md
```

## ‏מה נכתב כאן

**‏מרדכי** כותב entry לכל brief שחותם ל-dispatch:
- ‏הרציונל: ‏למה בחרנו גישה זו (לא "מה בוצע")
- ‏ממצאי אביגיל בתמצית
- ‏שינויי-כיוון אם שינינו לפי ממצאי אביגיל
- ‏רעיונות שנשקלו ונדחו

## ‏מה לא נכתב כאן

- ❌ ‏ביצוע (זה ב-`docs/walkthrough.md` בריפו הפרויקט — אליעזר כותב)
- ❌ ‏ממצאי אימות גולמיים (זה ב-`reports/` — אביגיל וכלב כותבים)

## ‏ההבחנה הכפולה

| ‏קובץ | ‏ריפו | ‏כותב | ‏תוכן |
|------|------|------|------|
| `docs/walkthrough.md` | ‏פרויקט | ‏אליעזר | ‏ביצוע — מה קרה, כרונולוגי |
| `docs/decisions/<project>.md` | ‏שיטה | ‏מרדכי | ‏רציונל — למה, שינויי-כיוון |
| `reports/<project>/*.json` | ‏שיטה | ‏אביגיל + כלב | ‏ממצאי אימות גולמיים |
