# Decisions — ‏יומן-החלטות של מרדכי

‏תיקייה זו מכילה את יומן-ההחלטות של **‏השיטה עצמה** (brief-driven-slices) —
‏`bds.md`. ‏מרדכי כותב כאן רק כשהוא מתכנן slice של השיטה עצמה.

> **‏לפרויקטים אחרים** (voice-acp, ‏וכו'): ‏ה-decisions חיים **‏בריפו של אותו
> ‏פרויקט** (`<project-repo>/docs/decisions/<project>.md`), ‏ליד הקוד — ‏לא כאן.
> ‏הרציונל של פרויקט שייך לפרויקט (clone/שיתוף/לוקאליות). ‏ריפו השיטה מחזיק רק
> ‏את ה-decisions *‏של השיטה*.

## ‏מבנה

```
docs/decisions/
└── bds.md     # רק השיטה עצמה. פרויקטים אחרים → בריפו שלהם.
```

## ‏מה נכתב כאן

**‏מרדכי** כותב entry לכל brief שחותם ל-dispatch:
- ‏הרציונל: ‏למה בחרנו גישה זו (לא "מה בוצע")
- ‏ממצאי אביגיל בתמצית
- ‏שינויי-כיוון אם שינינו לפי ממצאי אביגיל
- ‏רעיונות שנשקלו ונדחו

## ‏מה לא נכתב כאן

- ❌ ‏ביצוע (זה ב-`docs/walkthrough.md` בריפו הפרויקט — אליעזר כותב)
- ❌ ‏ממצאי אימות גולמיים (זה ב-`reports/` — אביגיל וכלב כותבים)

## ‏ההבחנה הכפולה

| ‏קובץ | ‏ריפו | ‏כותב | ‏תוכן |
|------|------|------|------|
| `docs/walkthrough.md` | ‏**‏פרויקט** | ‏אליעזר | ‏ביצוע — מה קרה, כרונולוגי |
| `docs/decisions/<project>.md` | ‏**‏פרויקט** | ‏מרדכי | ‏רציונל — למה, שינויי-כיוון |
| `reports/<project>/*.json` | ‏**‏שיטה** | ‏אביגיל + כלב | ‏ממצאי אימות גולמיים (זיקוק חוצה-פרויקטי) |

> walkthrough + decisions = ‏ליד הקוד (פרויקט). reports = ‏מרכזי (שיטה, ‏מצטבר).
