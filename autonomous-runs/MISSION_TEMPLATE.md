## §7 — נקודות-העיניים

1. **פריוויו חי** — בילד production, לא HMR. רק לסלייס עם UI.
2. **אישור merge** — ורק המיזוג ש**יוצא** מגבול ההרצה.

### אילו מיזוגים מגודרים

| מיזוג | מי מאשר |
|---|---|
| slice → **ענף-ההרצה** | **מרדכי, אוטונומי** — צנרת פנימית |
| ענף-ההרצה → `dev`/`main`/אינטגרציה משותפת | 🔒 **המשתמש בלבד** |

> בלי ענף-הרצה משלה, שרשרת אוטונומית **נעצרת אחרי הסלייס הראשון** — כל סלייס
> צריך את קודמו. השער אינו "מיזוג", אלא **מיזוג שיוצא מגבול ההרצה**.

## §8 — חובת-ראיה  🔴

**כל טענת-סטטוס מלווה בפקודה שהפיקה אותה, ובפלט שלה.**

| טענה | הראיה המחייבת |
|---|---|
| "בוצע" / "מקומט" | `git log --oneline <base>..HEAD` |
| "נקי" / "אין שינויים" | `git status --short` |
| "עבר" / "ירוק" | הרצת השער עצמה + הפלט |
| **"verdict X"** | `stat` על קובץ-הדוח **+ חיפוש דוח נוסף בנתיב אחר** |
