## §2 — 🔴 תנאי־העצירה שלא התקיים, ולמה זה נמדד ולא הונח

פקודת־המשימה §6.1: *"התוספת ל-`pre-push` מפילה push של סשן מקביל ⇒ עצור."*

| מה נמדד | התוצאה |
|---|---|
| `git config --show-origin core.hooksPath` | `file:…/.bare/config` ⇒ `.githooks` — **יחסי**, בקונפיג **המשותף** |
| `git rev-parse --git-path hooks` | `.githooks` ⇒ נפתר **פר־עץ־עבודה** |
| `git worktree list` | **57 עצים** · **12** נושאים `pre-push` · **45 אינם** |
| מעבדת־אימות (כלב) | עץ עם hook משלו ⇒ **שלו** רץ · עץ בלי `.githooks/` ⇒ **אף hook לא רץ** · מתת־תיקייה ⇒ נפתר לשורש העץ · `git -C` מבחוץ ⇒ אותו דבר |

🔴 **וההרצה בעץ זר — פעמיים, כי בפעם הראשונה היא הייתה ריקה.**

אליעזר דיווח "זהה לפני ואחרי" על `.worktrees/agent-charter`. נמדד:
**לעץ הזה אין `pre-push` בכלל** (רק `pre-commit`) ⇒ שום hook לא רץ בשני הצעדים,
ו"זהה" הוא טאוטולוגיה. ‏**ובנוסף `rc` היה 128 ולא 0** כפי שדווח.
ה-403 היה באג־חשבון מתועד (‏`gh` פעיל = `tzlev-admin` במקום `MusiCode1`).

מרדכי הריץ מחדש בעץ שכן נושא `pre-push`, ועם החשבון הנכון לפי
`runbooks/git-push-fails-when-gh-account-switched.md` — **בלי החלפה גלובלית**:

```bash
$ cd .worktrees/attach-status-gate
$ GH_TOKEN=$(gh auth token -u MusiCode1) git push --dry-run origin HEAD
rc=0
✅ size/impurity ratchet: no growth          ← ‏ורק היא
 * [new branch]  HEAD -> slice/attach-status-gate
```

🔑 **שורת ה-ratchet היא ההוכחה:** ה-hook של אותו עץ **באמת רץ**, והוא הגרסה
**הישנה** (בלי שורת־הטריות). ⇒ השינוי בלתי־נראה לסשן המקביל.
**תנאי־העצירה אינו מתקיים — על ראיה, לא על היעדר.**
